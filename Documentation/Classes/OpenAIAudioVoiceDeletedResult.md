# OpenAIAudioVoiceDeletedResult

The `OpenAIAudioVoiceDeletedResult` class contains the result of the deletion of a [voice](OpenAIAudioVoicesAPI.md#delete) or of a [consent recording](OpenAIAudioVoiceConsentsAPI.md#delete).

## Inherits

[OpenAIResult](OpenAIResult.md)

## Computed properties

| Property  | Type                                                  | Description |
|-----------|-------------------------------------------------------|-------------|
| `deleted` | [OpenAIAudioVoiceDeleted](OpenAIAudioVoiceDeleted.md) | The deletion status, or `Null` if the response is not valid. |
