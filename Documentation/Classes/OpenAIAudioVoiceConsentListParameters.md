# OpenAIAudioVoiceConsentListParameters

The `OpenAIAudioVoiceConsentListParameters` class contains the parameters to [list consent recordings](OpenAIAudioVoiceConsentsAPI.md#list).

## Inherits

[OpenAIParameters](OpenAIParameters.md)

## Properties

| Property | Type    | Description |
|----------|---------|-------------|
| `after`  | Text    | A cursor for use in pagination: the ID of the last object of the previous page. |
| `limit`  | Integer | A limit on the number of objects to be returned, from 1 to 100. Default: 20. |
