# OpenAIAudioVoiceConsentResult

The `OpenAIAudioVoiceConsentResult` class contains the result of creating, retrieving or updating a [consent recording](OpenAIAudioVoiceConsentsAPI.md).

## Inherits

[OpenAIResult](OpenAIResult.md)

## Computed properties

| Property  | Type                                                  | Description |
|-----------|-------------------------------------------------------|-------------|
| `consent` | [OpenAIAudioVoiceConsent](OpenAIAudioVoiceConsent.md) | The consent recording, or `Null` if the response is not valid. |
