# OpenAIAudioVoiceDeleted

The `OpenAIAudioVoiceDeleted` class is the deletion status of a voice or of a consent recording.

## Properties

| Property  | Type    | Description |
|-----------|---------|-------------|
| `id`      | Text    | The ID of the deleted object. |
| `deleted` | Boolean | Whether the object was successfully deleted. |
| `object`  | Text    | The object type: `audio.voice.deleted` for a voice, `audio.voice_consent` for a consent recording. |
