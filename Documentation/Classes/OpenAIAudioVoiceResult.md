# OpenAIAudioVoiceResult

The `OpenAIAudioVoiceResult` class contains the result of a [voice creation](OpenAIAudioVoicesAPI.md#create).

## Inherits

[OpenAIResult](OpenAIResult.md)

## Computed properties

| Property | Type                                    | Description |
|----------|-----------------------------------------|-------------|
| `voice`  | [OpenAIAudioVoice](OpenAIAudioVoice.md) | The voice created, or `Null` if the response is not valid. |
